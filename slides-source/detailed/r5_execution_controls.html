DAY 1 · MD §D1.3.9 · CONTROLLED EXECUTION

生成可以灵活，权限与发布必须受控Flexible generation, controlled access and release

以 ITEM WMS 本地机制为例：控制落在令牌、接口、沙箱和发布流程里，不只依赖 Prompt。In the local ITEM WMS implementation, tokens, APIs, sandboxing and release workflows enforce controls—not prompts alone.

Agent 可以帮助做什么What the Agent can help with系统如何守住边界How the system enforces boundaries

替用户查询与操作Read and act for the user

用户委托令牌，不是超级用户。角色权限、仓库范围和任务归属由系统检查；用户不能做的，Agent 也不能做。A delegated user token, not superuser access. The system checks roles, warehouse scope and task ownership; the Agent cannot exceed the user’s access.

按需求生成取数逻辑Generate view logic on demand

只读 View + WebAssembly 沙箱。代码按内容哈希不可变保存；无文件系统、无环境变量、不能访问其他网络，只拿当前用户只读令牌。Read-only View + WebAssembly sandbox. Content-hashed immutable code has no filesystem, environment variables or other network access; only the user’s read-only token.

当场生成与修改应用Generate and revise apps live

草稿 → 试运行 → 授权发布。草稿仅作者可见；发布预览所需接口权限；生产导入定制包仍为草稿，不能自动上线。Draft → trial → authorized release. Drafts are author-only; release previews API permissions; imported production packages remain drafts, not live apps.

执行后留痕、出错可回退Trace changes and recover versions

人、页面、版本与库存流水关联。版本可停用、可回退；版本回退不等于自动撤销已发生的库存或业务动作。Link operator, page, version and stock transactions. Versions can be disabled or rolled back; version rollback does not automatically undo completed business actions.
