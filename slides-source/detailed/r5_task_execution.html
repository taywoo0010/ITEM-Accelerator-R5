DAY 1 · MD §D1.3.7 · TASK LIFECYCLE

三类工作面，承接同一条任务链Three work surfaces, one task lifecycle

业务专家定义含义，建设者组织能力，使用者提出需求与确认结果；不是人人都先学开发。Experts define meaning, builders create capabilities, and users request work and confirm results.

01 · DEFINE

Ontology Studio

业务 Owner · 专家 · 共建者Owners · experts · co-builders

把对象、关系、规则、流程与 Action 边界说清楚；结合数据语义，审核有效范围。Define objects, rules and action boundaries; bind data semantics and review scope.

输出：共同业务语言Output: shared business meaning

02 · BUILD

Agent Factory

FDE · Senior User · DeveloperFDEs · senior users · developers

将本体、接口和规则组织为 Agent、Workflow 与工具能力；承接测试、审核和发布。Build agents, workflows and tools from ontology and APIs; test, review and release.

输出：可测试、可调用能力Output: testable, callable capabilities

03 · USE

ITEMGPT Runtime

业务用户 · 一线人员Business users · frontline staff

自然语言提出需求，使用 Agent 和动态页面；在自己的权限内试用、确认并执行任务。Request work, use agents and dynamic pages; confirm and act within personal access.

输出：交互与业务结果Output: interaction and outcomes
